# BDK Electrum

BDK Electrum extends [`electrum-client`] to update [`bdk_chain`] structures
from an Electrum server.

## Minimum Supported Rust Version (MSRV)
This crate has a MSRV of 1.85.0.

To build with the MSRV you will need to pin dependencies by running the
[`pin-msrv.sh`](https://github.com/bitcoindevkit/bdk/blob/master/ci/pin-msrv.sh) script.

[`electrum-client`]: https://docs.rs/electrum-client/
[`bdk_chain`]: https://docs.rs/bdk-chain/
